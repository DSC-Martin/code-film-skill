# code-film：用程式畫出來的短片

作者：李孟翰（Meng-Han Lee）｜2026-09

一個給 Claude Code 用的 skill。叫 Claude 做影片時，它不去生成影片，而是**寫一支會把影片一格一格畫出來的程式**：
畫面用 [Remotion](https://www.remotion.dev/)（React）逐格渲染，配樂用 Python 合成，兩邊讀同一份時間表，所以聲音和畫面天生對齊。

## 它幫 Claude 多做了什麼

- **一套做片流程**：範圍 → 真實性 → 分鏡 → 動態 → 聲音 → 驗收，六個階段
- **兩種模式**：產品片（功能展示、提案）和敘事片（小故事、手繪墨線風、角色動畫、節拍剪接）
- **機器驗收**：`verify.py` 檢查規格、第一格不能空白、轉場不疊影、聲畫同步、不能長時間不動、沒有突兀音量、剪接落在拍子上；沒過就不算完成
- **踩坑表**：每一條都是實際做片時踩過的
- **開箱就能渲染的樣板**：手繪墨線、鏡頭移動、游標、手機框、瀏覽器框等元件

## 怎麼裝

把 `code-film` 資料夾放到下面其中一個位置：

- 所有專案都能用：`~/.claude/skills/code-film/`
- 只給某個專案用：`<你的專案>/.claude/skills/code-film/`

## 怎麼用

在 Claude Code 裡直接說你要什麼，例如：

> 做一支 30 秒的中秋節影片，剪紙風，附上這張大樓的照片，結尾寫「中秋節快樂」。調用相關 skill。

Claude 會自己判斷要不要用這個 skill，不用記指令。

需要 Node.js 和 Python（numpy、scipy），以及 ffmpeg。
